# Online Budget App — Non‑Negotiable Product Principles

Status: Permanent Strategic Guardrail
Last Updated: 2026-02-22
Scope: All Future Decisions (Beyond V1 Included)

---

# PURPOSE

This document defines principles that cannot be violated without explicit strategic reconsideration.

These principles protect:

- Product identity
- User trust
- Financial correctness
- Long-term sustainability
- Architectural coherence

If a future idea conflicts with these principles, the idea is wrong — not the principles.

---

# 1. Financial Truth Is Sacred

- All financial calculations must be deterministic.
- All money stored in minor units.
- ISO 4217 currency compliance.
- One shared financial engine.
- No duplicate math logic anywhere.

Trust in numbers is the foundation of the product.
If users doubt the math, the product dies.

---

# 2. Offline Sovereignty Must Always Exist

The Offline version is not a teaser.
It is a legitimate sovereign financial tool.

- Users must be able to use core financial modeling without cloud dependence.
- Offline must never be crippled to force upgrades.

Online differentiates via automation, not artificial restriction.

---

# 3. Online = Automation + Intelligence (Not Feature Bloat)

Online exists to:

- Remove manual effort
- Provide AI-driven clarity
- Sync data across devices

Online does NOT exist to:

- Become a full financial SaaS suite
- Replace accounting software
- Become an investment platform

If a feature does not strengthen automation or clarity, it does not belong.

---

# 4. AI Is an Assistant, Not an Authority

AI must:

- Explain
- Summarize
- Highlight

AI must never:

- Perform financial calculations
- Give regulated advice
- Replace deterministic systems

AI is a narrator layered on top of truth.

---

# 5. Scope Discipline Is Survival

Every feature must pass this filter:

1. Does it align with budgeting + clarity?
2. Does it protect engine unity?
3. Does it avoid regulatory expansion?
4. Does it preserve architectural simplicity?

If any answer is no → Do not build.

---

# 6. Margin Discipline Is Non-Negotiable

Bank integrations and AI cost real money.

- Free users must not create structural losses.
- Subscription must align cost with revenue.
- Gross margin must be protected.

A product that grows but loses money structurally is not sustainable.

---

# 7. Transparency Over Illusion

We must never:

- Fake real-time sync
- Hide sync failures
- Hide AI uncertainty
- Obscure subscription terms

Users tolerate imperfection.
They do not tolerate deception.

---

# 8. Consistency Across Modes

Offline and Online must:

- Share the same financial engine
- Share the same budgeting logic
- Share the same currency model

If totals differ between modes, trust collapses.

---

# 9. Simplicity Wins

Prefer:

- Clear UI
- Few pricing tiers
- Small focused features
- Strong defaults

Avoid:

- Feature matrices
- Configuration overload
- Enterprise-level complexity

Complexity accumulates silently and kills velocity.

---

# 10. Build for 5 Years, Not 5 Weeks

Short-term growth hacks must never:

- Break architecture
- Introduce financial inconsistency
- Create tech debt that blocks future alignment

Every major decision must ask:

"Does this still make sense in 5 years?"

---

# 11. Protect the Core Asset

The shared financial engine is the core asset.

UI can change.
AI models can change.
Providers can change.

The engine must remain stable, versioned, and protected.

---

# 12. If in Doubt, Build Less

Feature restraint is strategic strength.

We are not trying to become everything.
We are trying to become trusted.

---

# FINAL DECLARATION

This product is:

- A financial clarity system
- Powered by deterministic math
- Enhanced by AI
- Automated through bank sync
- Grounded in sovereignty

It is not a financial empire.

If future decisions drift from this identity,
this document overrides them.
