# Browser Commands

AI-optimized browser automation using agent-browser (vercel-labs).

## Available Commands

- [open](./open.md) - Navigate to URL
- [snapshot](./snapshot.md) - Get interactive page snapshot with element refs
- [screenshot](./screenshot.md) - Capture page screenshot
- [close](./close.md) - Close browser session
- [scrape](./scrape.md) - Content scraping workflow
- [visual-test](./visual-test.md) - Visual regression testing
